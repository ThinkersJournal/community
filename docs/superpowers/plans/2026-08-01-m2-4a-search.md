# M2.4a Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Anonymous, typo-tolerant search over all published posts and onboarded people, via `GET /public/search`, with a tabbed `/search` page and a nav search box.

**Architecture:** Postgres `pg_trgm` trigram fuzzy matching (partial expression GIN indexes over posts and profiles), ranked by `word_similarity` inside a `SET LOCAL`-threshold transaction, exposed as one anonymous offset-paginated `/public/search?q=&type=&offset=` endpoint. A server-rendered `/search` page (Posts | People tabs) and a `<form>` in the shared nav are the front end; the page is short-TTL edge-cached.

**Tech Stack:** TypeScript 6, Cloudflare Workers (`apps/api` Worker, `apps/web` Astro SSR), Postgres 18 + `pg_trgm` via Hyperdrive, `pg` client, node-pg-migrate (SQL migrations), Vitest (`@cloudflare/vitest-pool-workers` + Node `*.db.test.ts`), Playwright e2e.

## Global Constraints

Every task implicitly includes this section. Values verbatim from `docs/superpowers/specs/2026-08-01-m2-4a-search-design.md`.

- **Extension:** `CREATE EXTENSION IF NOT EXISTS pg_trgm` (migration 0009). Neon-allowed; in the `postgres:18` image.
- **Index expression MUST equal the query expression byte-for-byte**, or Postgres ignores the index. Posts: `lower(title || ' ' || coalesce(markdown_source, ''))`, partial `WHERE status = 'published'`. People: `lower(coalesce(username::text, '') || ' ' || coalesce(display_name, '') || ' ' || coalesce(bio, ''))`, partial `WHERE username_chosen = true`. Both `USING gin (... gin_trgm_ops)`.
- **Matching:** the word-similarity operator (`lower($q) <% <indexed_expr>`) for the GIN-indexed filter; **rank** `ORDER BY word_similarity(lower($q), <expr>) DESC, <id> DESC`. NOT `similarity` (length-skewed), NOT `ILIKE`.
- **Threshold:** each search runs in a transaction that first sets `SET LOCAL pg_trgm.word_similarity_threshold = 0.3` (the strict 0.6 default kills recall). `SET LOCAL` requires an explicit `BEGIN … COMMIT` (see `db/client.ts` header — the only mechanism that survives Hyperdrive pooling).
- **`$q` is always a bind parameter** — never interpolated. The similarity operator makes `%`/`_` literal, so no escaping.
- **No draft / un-onboarded leakage:** posts `status = 'published'`; people `username_chosen = true` — in BOTH the query WHERE and the partial index predicate.
- **Endpoint:** `GET /public/search?q=&type=&offset=`, anonymous (no session read), `HYPERDRIVE_FRESH`, response `cache-control: no-store`. Register in the anonymous-social block of `routes.ts`.
- **Validation → `errorResponse("INVALID_INPUT", 400, { fields:[…] })`:** `q` trimmed, length **2–100** (`SEARCH_Q_MIN`/`SEARCH_Q_MAX`); `type` ∈ `{posts, people}`, default `posts`; `offset` integer `0 ≤ offset ≤ 200` (`SEARCH_MAX_OFFSET`), else 400.
- **Pagination:** `LIMIT SEARCH_PAGE_SIZE + 1` (`SEARCH_PAGE_SIZE = 20`) → `hasMore` sentinel (no total count); `nextOffset = (hasMore && offset + PAGE_SIZE <= SEARCH_MAX_OFFSET) ? offset + PAGE_SIZE : null` (pager stops before the cap).
- **Web page:** `apps/web/src/pages/search.astro` — anonymous `apiFetch` (no `request`), `markFeedCacheable(Astro)` (exactly one cache helper — enforced by `page-cache-inventory.test.ts`), `setPublicPageCsp(Astro)`, **no client JS**. Nav search box is a static `<form method="GET" action="/search">` (Nav.astro carries no `apiFetch`/`Astro.request` — enforced by `nav.test.ts`).
- **Migrations apply:** db/unit tests + CI e2e apply 0009 automatically; **LOCAL dev/e2e requires `pnpm --filter @thinkersjournal/api migrate` by hand** (the persistent dev DB does not self-migrate).

```sql
-- Up Migration

-- Trigram fuzzy search (M2.4a). pg_trgm ships in the postgres:18 image and is
-- Neon-allowed; it powers typo-tolerant / partial matching over posts + people.
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- Posts: PARTIAL expression GIN over lowercased title+body, published-only (search
-- never returns drafts). lower(...) because trigram is case-sensitive; the
-- expression (not a stored column) avoids duplicating the body. The expression here
-- MUST match the query in src/routes/search.ts byte-for-byte or it won't be used.
CREATE INDEX posts_search_trgm_idx ON posts
  USING gin (lower(title || ' ' || coalesce(markdown_source, '')) gin_trgm_ops)
  WHERE status = 'published';

-- People: PARTIAL expression GIN over lowercased username+display_name+bio,
-- onboarded-only. username is citext → cast to text for concat.
CREATE INDEX profiles_search_trgm_idx ON profiles
  USING gin (lower(coalesce(username::text, '') || ' ' || coalesce(display_name, '') || ' ' || coalesce(bio, '')) gin_trgm_ops)
  WHERE username_chosen = true;

-- Down Migration
DROP INDEX IF EXISTS profiles_search_trgm_idx;
DROP INDEX IF EXISTS posts_search_trgm_idx;
DROP EXTENSION IF EXISTS pg_trgm;
```

```ts
/**
 * Search wire types (M2.4a). Anonymous /public/search returns one page of either
 * posts or people (the tab the caller asked for), offset-paginated with a
 * hasMore-derived nextOffset (no total count).
 */
export const SEARCH_TYPES = ["posts", "people"] as const;
export type SearchType = (typeof SEARCH_TYPES)[number];

export interface SearchPostResult {
  id: string;
  title: string;
  slug: string;
  /** left(markdown_source, 400) — raw markdown; render via markdownExcerpt (never set:html). */
  excerptSource: string;
  publishedAt: string;
  authorUsername: string;
  authorDisplayName: string | null;
}

export interface SearchPersonResult {
  username: string;
  displayName: string | null;
  bio: string | null;
}

export interface SearchPage<T> {
  results: T[];
  /** The offset for the next page, or null when there is no next page (incl. at the offset cap). */
  nextOffset: number | null;
}

export const SEARCH_PAGE_SIZE = 20;
export const SEARCH_Q_MIN = 2;
export const SEARCH_Q_MAX = 100;
export const SEARCH_MAX_OFFSET = 200;
```

`apps/api/src/routes/search.ts`:

```ts
/**
 * ANONYMOUS SEARCH (M2.4a). A /public/* read — no session, viewer-independent,
 * HYPERDRIVE_FRESH, response no-store (the /search PAGE is short-TTL edge-cached;
 * this api response is not). pg_trgm word-similarity fuzzy match over published
 * posts and onboarded people, offset-paginated with a hasMore sentinel.
 *
 * ⚠️ The `<%` filter expression MUST match the partial GIN index in migration
 * 0009 byte-for-byte, or Postgres falls back to a seq scan. `$1` is always a bind
 * param (the similarity operator makes %/_ literal — no escaping). The search runs
 * inside a BEGIN…COMMIT so `SET LOCAL pg_trgm.word_similarity_threshold` takes
 * effect (SET LOCAL is the only threshold mechanism that survives Hyperdrive
 * transaction-mode pooling — see src/db/client.ts).
 */
import { withClient } from "../db/client";
import { errorResponse } from "../http/errors";

import {
  SEARCH_MAX_OFFSET, SEARCH_PAGE_SIZE, SEARCH_Q_MAX, SEARCH_Q_MIN,
} from "@thinkersjournal/shared";
import type { SearchPersonResult, SearchPostResult } from "@thinkersjournal/shared";

function json(body: unknown): Response {
  return new Response(JSON.stringify(body), {
    status: 200,
    headers: { "content-type": "application/json", "cache-control": "no-store" },
  });
}

const POSTS_SQL = `
  SELECT p.id, p.title, p.slug,
         left(p.markdown_source, 400) AS "excerptSource",
         p.published_at AS "publishedAt",
         pr.username AS "authorUsername",
         pr.display_name AS "authorDisplayName"
    FROM posts p
    JOIN profiles pr ON pr.user_id = p.author_id
   WHERE p.status = 'published'
     AND lower($1) <% lower(p.title || ' ' || coalesce(p.markdown_source, ''))
   ORDER BY word_similarity(lower($1), lower(p.title || ' ' || coalesce(p.markdown_source, ''))) DESC,
            p.id DESC
   LIMIT $2 OFFSET $3`;

const PEOPLE_SQL = `
  SELECT pr.username, pr.display_name AS "displayName", pr.bio
    FROM profiles pr
   WHERE pr.username_chosen = true
     AND lower($1) <% lower(coalesce(pr.username::text,'') || ' ' || coalesce(pr.display_name,'') || ' ' || coalesce(pr.bio,''))
   ORDER BY word_similarity(lower($1), lower(coalesce(pr.username::text,'') || ' ' || coalesce(pr.display_name,'') || ' ' || coalesce(pr.bio,''))) DESC,
            pr.user_id DESC
   LIMIT $2 OFFSET $3`;

export async function handlePublicSearch(
  request: Request, env: Env, ctx: ExecutionContext,
): Promise<Response> {
  const url = new URL(request.url);
  const q = (url.searchParams.get("q") ?? "").trim();
  const type = url.searchParams.get("type") ?? "posts";
  const offsetRaw = url.searchParams.get("offset");

  if (q.length < SEARCH_Q_MIN || q.length > SEARCH_Q_MAX) {
    return errorResponse("INVALID_INPUT", 400, { fields: ["q"] });
  }
  if (type !== "posts" && type !== "people") {
    return errorResponse("INVALID_INPUT", 400, { fields: ["type"] });
  }
  const offset = offsetRaw === null ? 0 : Number(offsetRaw);
  if (!Number.isInteger(offset) || offset < 0 || offset > SEARCH_MAX_OFFSET) {
    return errorResponse("INVALID_INPUT", 400, { fields: ["offset"] });
  }

  const limit = SEARCH_PAGE_SIZE + 1;
  const page = await withClient(env.HYPERDRIVE_FRESH, ctx, async (c) => {
    // One simple-query BEGIN sets the threshold for this transaction only.
    await c.query("BEGIN; SET LOCAL pg_trgm.word_similarity_threshold = 0.3");
    try {
      const { rows } =
        type === "posts"
          ? await c.query<SearchPostResult>(POSTS_SQL, [q, limit, offset])
          : await c.query<SearchPersonResult>(PEOPLE_SQL, [q, limit, offset]);
      await c.query("COMMIT");
      const hasMore = rows.length > SEARCH_PAGE_SIZE;
      const results = rows.slice(0, SEARCH_PAGE_SIZE);
      const nextOffset =
        hasMore && offset + SEARCH_PAGE_SIZE <= SEARCH_MAX_OFFSET ? offset + SEARCH_PAGE_SIZE : null;
      return { results, nextOffset };
    } catch (err) {
      await c.query("ROLLBACK").catch(() => {});
      throw err;
    }
  });
  return json(page);
}
```

```astro
 * `GET /search?q=&type=&offset=` — anonymous trigram search (M2.4a).
 * ⚠️ ANONYMOUS + short-TTL EDGE-CACHEABLE (markFeedCacheable: untagged, 60s/600s;
 * the querystring is part of the cache key). No client JS — forms + links only.
 * A missing/too-short q renders the empty search box and makes NO api call.
 */
import PageLayout from "../components/PageLayout.astro";
import { apiFetch } from "../lib/api";
import { markFeedCacheable } from "../lib/cache";
import { setPublicPageCsp } from "../lib/csp";
import { markdownExcerpt } from "@thinkersjournal/markdown";

import { SEARCH_Q_MIN } from "@thinkersjournal/shared";
import type { SearchPage, SearchPersonResult, SearchPostResult } from "@thinkersjournal/shared";

const q = (Astro.url.searchParams.get("q") ?? "").trim();
const type = Astro.url.searchParams.get("type") === "people" ? "people" : "posts";
const offsetParam = Number(Astro.url.searchParams.get("offset"));
const offset = Number.isInteger(offsetParam) && offsetParam > 0 ? offsetParam : 0;

const active = q.length >= SEARCH_Q_MIN;

let posts: SearchPage<SearchPostResult> = { results: [], nextOffset: null };
let people: SearchPage<SearchPersonResult> = { results: [], nextOffset: null };

if (active) {
  const qs = new URLSearchParams({ q, type, offset: String(offset) });
  const res = await apiFetch<SearchPage<SearchPostResult | SearchPersonResult>>(`/public/search?${qs.toString()}`);
  const data = res.status === 200 && res.data !== null ? res.data : { results: [], nextOffset: null };
  if (type === "people") people = data as SearchPage<SearchPersonResult>;
  else posts = data as SearchPage<SearchPostResult>;
}

// Build a tab/pager href preserving q, swapping type / offset.
const href = (t: "posts" | "people", o: number) =>
  `/search?${new URLSearchParams({ q, type: t, offset: String(o) }).toString()}`;

markFeedCacheable(Astro);
setPublicPageCsp(Astro);
```
